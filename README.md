# NeurIPS papers — restructured workspace

Parent repository for the three NeurIPS theory papers, each living as an independent submodule. Designed for the segmented-paper workflow: each paper repo carries `src/` segments + `OUT.*` concatenation manifests (one per intended output, e.g. `OUT.full-paper.md`, `OUT.neurips-2026-paper.md`), so the same prose feeds multiple assemblies (full-works, NeurIPS-trimmed, future venues, journal versions).

Modeled on the assembly pattern used in `~/src/agentic-systems/` (per-component `OUTLINE.md` tables that double as concat manifests).

This repository is being migrated from `~/src/neurips2026/`. See `MIGRATION.md` for the migration log.
